GREEN — works. Reading the numbers down a column (120 → 140 → 155 → 170) gives a trend over time. Plotting the automated column against the manual column as two lines over the shared week axis also works — each column is already its own ready-made series.

RED — impossible. The headers automated and manual are structure, not data. To draw a donut you'd have to group by them as if they were one category — but there is no column whose values are "automated"/"manual". A chart can only group on values inside a column, and here they're column names. So: no donut, no share %, no stacked breakdown from this shape.

GREEN — now possible. The exact same labels automated / manual have moved out of the headers and into the type column as values. Because they're values now, a chart can group by type — which is precisely what a donut, pie, or stacked bar needs.

The whole rule in one line: a chart can only compare things stored as values inside a column, never things stored as column headers. Reshaping wide → long just moves your category from the header row down into a column so it becomes groupable.
